This repository contains the DJI Mobile SDK for Android (V5), which enables developers to create Android applications for DJI drones and products.

- **SampleCode-V5/**: Example projects and sample code for using the SDK.

## Getting Started

1. **Clone the Repository**
   ```sh
   gh repo clone dji-sdk/Mobile-SDK-Android-V5
   ```
2. **Open the Project**
   - Open the `SampleCode-V5/android-sdk-v5-as` or `SampleCode-V5/android-sdk-v5-sample` folder in Android Studio.
3. **Build and Run**
