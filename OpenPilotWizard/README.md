# Open Pilot Wizard (OPW)

[中文版](README_CN.md)

## What is OPW?

Open Pilot Wizard (OPW) is a toolkit for developing DJI Pilot plugins with AI. It provides AI coding tools with plugin development knowledge, project templates, and workflows, so you can describe your requirements in natural language and let AI help create projects, write code, and verify results.

OPW is not a standalone AI coding tool. It works with **OpenCode, Claude Code, or Codex**.

## What problems does it solve?

Pilot plugin development involves more than business logic: plugin entry points, App Key binding, SDK version compatibility, and remote controller debugging also need attention. General-purpose AI can miss these details, producing code that fails to compile or plugins that Pilot cannot recognize.

OPW helps AI consult development references before implementing changes. It supports:

- **Creating plugins**: Generate a basic project, UI, and Pilot plugin entry point from an empty directory.
- **Development and maintenance**: Add features, adjust UI, troubleshoot issues, and refactor code.
- **App migration**: Assess and migrate an existing MSDK Android app into a Pilot plugin.
- **Technical questions**: Look up APIs, error codes, and component usage without modifying project code.

For development tasks, AI proposes a plan and waits for your approval before implementation. Progress is saved in the project, so interrupted sessions can resume.

## Installation

### 1. Prepare your environment

- macOS (Apple Silicon / Intel), or Windows 10 22H2 / 11 x64.
- A working installation of OpenCode, Claude Code, or Codex, with an available model service.
- Internet access during installation. You do not need to install Node.js beforehand; the installer checks and installs it if needed.

### 2. Download the installer

Download the [OPW 1.0.0 installer](open-pilot-wizard-installer-1.0.0.zip): open the file page and use the raw-file download option to save the ZIP locally. If you have cloned this repository, use `open-pilot-wizard-installer-1.0.0.zip` in this directory directly; no additional download is needed.

### 3. Ask AI to install OPW

Start a new session in your AI tool and enter:

```text
I have downloaded the Open Pilot Wizard archive at <ZIP file path>.
Please follow INSTALL_AGENT.md in the archive to install Open Pilot Wizard for me.
Request approval whenever permissions are needed.
```

Replace `<ZIP file path>` with the absolute local path to the downloaded ZIP or the archive in your repository checkout. AI will extract the archive, explain the operations, and complete installation after receiving authorization. You still need to handle sign-in, key configuration, and license confirmation yourself.

> Your AI tool must have local file access and terminal execution capabilities. Uploading the ZIP to a chat window alone cannot install OPW on your computer.

Install OPW once and reuse it across projects. After installation, restart your terminal and AI tool. Run `opw --version` to check the installed version.

## Usage

### 1. Open your project and select the entry point

- **New plugin**: Open an empty directory in your AI tool.
- **Existing plugin or MSDK project to migrate**: Run `opw setup` in the project root. Projects generated by OPW do not need this step again.

| AI tool | Entry point |
| --- | --- |
| OpenCode | Press Tab to select `pilot-plugin-dev`, or use `@pilot-plugin-dev` in a message |
| Claude Code | Run `/output-style pilot-plugin-dev` |
| Codex | Invoke the `opw` Skill directly; no agent switching is needed |

### 2. Describe what you want

**Create a plugin:**

```text
Use OPW to create a Pilot plugin named "Flight Route Assistant" with the default icon.
Start with a basic page and the Pilot plugin entry point.
Propose a plan and wait for my approval before implementation.
```

**Add a feature:**

```text
Add an aircraft connection status display to the current plugin.
Explain the implementation plan and verification steps, and wait for my approval before changing code.
```

**Migrate an app:**

```text
Assess migrating the current MSDK app into a Pilot plugin.
Explain which features can be retained and which need changes. Wait for my approval before starting.
```

AI confirms the necessary details, proposes a plan, implements it after approval, and reports the build result. Install the APK on the remote controller, enable the plugin in Pilot's plugin management page, and verify its functionality.

> Before using MSDK capabilities, apply for and bind a DJI App Key using the final package name. A successful build does not guarantee correct runtime behavior. Review flight-control code and verify it on real hardware.

### Common commands

| Command | Purpose |
| --- | --- |
| `opw --version` | Show the installed version |
| `opw setup` | Initialize OPW configuration for the current project |
| `opw doctor` | Check whether the project and AI development capabilities are ready |
| `opw update` | Sync the installed OPW configuration to the current project; does not download a new version |

Learn more: [OPW developer documentation](https://developer.dji.com/doc/mobile-sdk-tutorial/en/Open-Pilot/ai-coding/overview.html).
