      class IARManager

      Package:dji.open.pilot.client.interfaces
      Description:

      AR management class. Note: First, upload the configuration to the Pilot, generate ARInfo using the configuration ID, and then set the ARInfo to the Pilot. One configuration can correspond to multiple ARInfo icons. SVG is supported, but there are requirements for the SVG file fields. For details, please refer to the Sample.

      Supported since MSDK 5.20.1

      enableARRadar
      method enableARRadar
      Package:dji.open.pilot.client.interfaces
      Description:

      Set the AR radar scan range configuration. When config.enable is false, the radar scan range display is disabled; when true, it is displayed according to the parameters. Note: Only one global radar scan range configuration is active at a time. Multiple calls are overridden by the latest one.

      Supported since MSDK 5.20.1

      Input Parameters:
      @NonNull ARRadarConfig configRadar scan range configuration.
      @NonNull CommonCallbacks.CompletionCallback callbackResult callback.

      ARIconProjectionType

      Package:dji.open.pilot.base.manager.ar
      Description:

      AR Projection Type Enumeration Indicates the projection method used to render elements in AR.

      Supported since MSDK 5.20.1

      Enum Members:
      NONENo projection, no icon is displayed.
      PERSPECTIVEPerspective projection, where objects appear larger when closer and smaller when farther away, is in line with the visual habits of the human eye.
      ORTHOGRAPHICOrthographic projection, size is independent of distance and maintains a fixed pixel size.
