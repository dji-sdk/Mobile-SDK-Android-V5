      updateMapWidgets
      method updateMapWidgets
      Package:dji.open.pilot.client.interfaces
      Description:

      Updates map widgets in batch.

      Widgets are matched by id and their properties are updated in place (without visual flicker). If the id of any widget in the list does not exist, or an attempt is made to modify an immutable field (id / source / layerId), the whole batch update fails and no IPC is issued.

      The following fields cannot be modified via this method, otherwise the WIDGET_FIELD_IMMUTABLE error is returned in the callback: id (unique widget identifier, immutable); source (source package name, immutable); layerId (the layer it belongs to; to move a widget to another layer, first call removeMapWidgetsByIds and then addMapWidgets again).

      Note: Due to the Android Binder transmission limit, the total data volume of a single batch update should not exceed 512KB. When exceeded, the PAYLOAD_TOO_LARGE error is returned in the callback.

      Supported since MSDK 5.20.1

      Input Parameters:
      @NonNull List<MapWidget> widgetsMap widget list.
      CommonCallbacks.CompletionCallback callbackResult callback.

      addMapWidgets
      method addMapWidgets
      Package:dji.open.pilot.client.interfaces
      Description:

      Adds map widgets in batch.

      Multiple widgets are added in a single IPC call, suitable for batch synchronization of GIS data.

      Note: Due to the Android Binder transmission limit, the total data volume of a single batch addition should not exceed 512KB. It is recommended not to exceed 500 simple Marker widgets, or 200 polyline/polygon widgets that contain coordinate lists at a time. When exceeded, the PAYLOAD_TOO_LARGE error is returned in the callback.

      Supported since MSDK 5.20.1

      Input Parameters:
      @NonNull List<MapWidget> widgetsMap widget list.
      CommonCallbacks.CompletionCallback callbackResult callback.

      addLayer
      method addLayer
      Package:dji.open.pilot.client.interfaces
      Description:

      Adds a layer.

      A layer is a logical grouping container for map widgets. It can organize MapWidgets into different layers by business semantics (such as “fire point layer”, “personnel layer”), and supports showing/hiding and clearing an entire layer. A layer can contain MapWidgets of any DrawerType.

      Supported since MSDK 5.20.1

      Input Parameters:
      @NonNull MapWidgetLayer layerLayer.
      CommonCallbacks.CompletionCallback callbackResult callback.
      method
      removeLayer
      method removeLayer
      Package:dji.open.pilot.client.interfaces
      Description:

      Removes a layer.

      This also removes all map widgets under the layer. The default layer (empty layerId) cannot be removed, otherwise the LAYER_READONLY error is returned in the callback. If the layer does not exist, the LAYER_NOT_FOUND error is returned in the callback.

      Supported since MSDK 5.20.1

      Input Parameters:
      @NonNull String layerIdLayer ID.
      CommonCallbacks.CompletionCallback callbackResult callback.
