      startPushingFileToMegaphone
      method startPushingFileToMegaphone
      包：dji.v5.manager.interfaces
      描述：

      传输TTS数据或者音频文件到喊话器。当数据传输完成后，你可以调用startPlay 接口进行播放。
      注意：流式传输模式的数据必须为 OPUS 编码格式的音频数据。如果是 MP3 文件，请用 PCMTools 转换为 OPUS 文件，从 MSDK 5.14.0 版本开始将不再支持通过 DJI 转化的 OPUS 文件。

      MSDK 5.0.0开始支持

      输入参数：
      @NonNull FileInfo fileInfo文件信息。
      @Nullable CommonCallbacks.CompletionCallbackWithProgress<Integer> callback返回执行结果的回调。
