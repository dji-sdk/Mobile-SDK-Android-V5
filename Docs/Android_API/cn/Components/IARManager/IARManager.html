      class IARManager

      包：dji.open.pilot.client.interfaces
      描述：

      AR管理接口。 注意： 先上传配置到Pilot，通过配置的ID，生成ARInfo，再设置ARInfo到Pilot。一个配置可以对应多个ARinfo 图标支持SVG，但对SVG文件字段有要求，具体可以参考Sample示例。据。

      enableARRadar
      method enableARRadar
      包：dji.open.pilot.client.interfaces
      描述：

      设置AR雷达扫描范围配置。当 config.enable 为 false 时关闭雷达扫描范围显示；为 true 时按参数显示。 注意：全局只有一个雷达扫描范围配置生效，多次调用以最后一次为准。
